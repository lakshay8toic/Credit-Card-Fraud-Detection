# Project Proposal

The original proposal material, submitted in September 2026 **before the work
was carried out**.

| File | What it is |
|---|---|
| `Project Proposal.pdf` | The written proposal — problem statement, planned approach, dataset, algorithms, expected results (12 pages) |
| `Proposal Deck.pptx` / `.pdf` | The slides presented at the proposal review (16 slides) |
| `Proposal Deck - Speaking Script.pdf` | Speaking notes for that deck, split across the four team members |

## A note on the tense

Everything in this folder is written in the future tense — "we **will** train",
"we **expect** ensembles to outperform single learners". That is correct for
what it is: a proposal describing work not yet done. The results it anticipates
are stated as hypotheses, not findings.

The project has since been completed. For what was actually built, measured and
concluded, see:

- [`../Report/`](../Report/) — the full project report
- [`../Presentation/`](../Presentation/) — the 30-slide explanation of the finished project
- [`../How To Explain/`](../How%20To%20Explain/) — what to say about it, and the likely questions
- [`../README.md`](../README.md) — results and findings

These files are kept for the record, so the proposal and the finished work can
be compared. Most of what was predicted held up; the notable exception is
documented in the report — the Bayes optimal threshold could not be applied to
naive Bayes until its probabilities were calibrated, which the proposal did not
anticipate.
